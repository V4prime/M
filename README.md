# Telegram Self-Bot Manager

ربات مدیریت سلف تلگرام با پنل دکمه‌ای چندصفحه‌ای - اجرا شده روی Render.com رایگان.

## 📋 قابلیت‌ها

- ورود با شماره + کد + رمز دوم (بدون نیاز به api_id/api_hash)
- اتصال همیشگی ۲۴ ساعته
- پنل ۵ صفحه‌ای (سلف، تبچی، پیام خودکار، پروفایل، امنیت)
- تبچی هوشمند با ضد ریپ
- ریکت خودکار، کامنت اول، چت AI
- ساعت زنده کنار اسم
- کپی پروفایل، تغییر بیو
- فضول‌یاب و ضد لاگین
